01Tuning

Tune by map, by name, or by neighbourhood

Explore puts a braille world map beside the station list. Move the single scan cursor with WASD or a click and the list reloads around that coordinate, sorted by true distance rather than popularity.

Search finds stations by name or genre and narrows by country, language, codec, and bitrate. Countries browses whole national lists. Nearby shows what is broadcasting around your approximate location.

NoteLocation is looked up only when you open Nearby, and can be switched off in Settings. Cached directory results remain available during provider outages.

02Library & logbook

Presets that stay put

Favorites, recent stations, and imported streams live in one library on your machine. There is no account to create and nothing to sync.

  • Add any direct HTTP(S) stream with automatic ICY metadata
  • Import M3U, PLS, or XSPF; export M3U
  • Named presets — radiocli play work
  • Track history, plus JSON backup and restore

The Stats screen keeps a 52-week activity graph with listening time, sessions, active days, streaks, and your most-listened station, recorded across TUI and CLI sessions alike.

03Display

424 receiver styles, one honest signal

Braille animation, ASCII geometry, waves, fire, cityscapes, and the Gallop display. Press v for the next receiver and t for one of 48 color themes; playback never skips.

The display moves only while audio is genuinely playing. Paused, loading, or failed streams return it to a flat zero-signal frame.

Full, compact, and micro layouts follow the window size. Unicode or ASCII rendering, reduced motion, screen-reader output, transparent backgrounds, and NO_COLOR are supported.

04Timer · beta

Clock radio, grown up

Schedule one-time or recurring alarms with explicit timezones, independent volume, fade-in, fallback stations, snooze, and auto-stop. A sleep timer handles the other end of the day.

Alarms register with launchd on macOS, Task Scheduler on Windows, or a systemd user timer on Linux, so they can ring after the terminal is closed.

CautionAlarms are in beta. Power settings, login state, and stream health can prevent sound; use a second device for anything critical.

05Remote control

A remote for your AI assistant

An optional Model Context Protocol (MCP) server exposes typed tools for discovery, playback, favorites, stats, alarms, AirPlay, and appearance. Ask for “something with birdsong” and let the assistant tune it.

$ radiocli setup --mcp
  • Opt-in, local, over stdio
  • Agents may play only library stations or RadioCLI’s own search results
  • radiocli agent gives non-MCP tools the same controls

06Shell operation

Operate it without looking

play starts background playback and returns your prompt. If the full-screen interface is already open, commands control that player instead. Both share one library and one history.

$ radiocli play jazz
$ radiocli now --watch
$ radiocli favorite
$ radiocli play --favorites --random
$ radiocli stop

08Questions

Questions & answers

What is RadioCLI?

RadioCLI is a free, open-source internet radio player that runs in your terminal. It has a full-screen terminal interface (TUI) for browsing and listening, and a scriptable command line for starting, pausing, and switching stations from your shell.

How do I install RadioCLI?

With Node.js 22 or newer: npm install -g @ciphore/radiocli, then radiocli setup. On macOS, brew install ciphore/tap/radiocli also installs Node.js, mpv, and FFmpeg. To try it without installing, run npx @ciphore/radiocli.

Do I need an account or subscription?

No. There is no account, no sign-in, and no cloud library. Favorites, recent stations, settings, track history, and listening stats are stored on your machine, with JSON backup and restore.

Which operating systems are supported?

macOS (Apple silicon and Intel), Ubuntu Linux (x64 and arm64), and Windows (x64 and arm64) are tested in CI on Node.js 22 and 24. FreeBSD, OpenBSD, and NetBSD are supported for the core package route. Other platforms such as Alpine, WSL, and Termux are experimental.

What do I need for audio playback?

RadioCLI plays streams through mpv, which provides pause, volume, mute, media keys, and live track metadata. ffplay and VLC work as playback-only fallbacks. radiocli setup shows a plan and helps install the tools for your system; radiocli doctor checks what is available.

Where do the stations come from?

Station discovery uses the public Radio Browser directory, with cached results that stay available during provider outages. You can also add any direct HTTP(S) stream URL and import M3U, PLS, or XSPF playlists.

Can an AI assistant control RadioCLI?

Yes, if you opt in. radiocli setup --mcp registers a local Model Context Protocol (MCP) server with typed tools for discovery, playback, favorites, stats, alarms, AirPlay, and appearance. It runs over stdio on your machine, and agents can only play stations from your library or from RadioCLI's own search results.

Can RadioCLI wake me up with a radio station?

Alarms are in beta. You can schedule one-time or recurring alarms with timezones, fade-in, fallback stations, snooze, and auto-stop. They register with launchd, Task Scheduler, or a systemd user timer, so the terminal does not need to stay open. Use a second device for anything critical.

What does RadioCLI send over the network?

It resolves public stream URLs and hands playback to your local player; it does not proxy audio. Nearby uses an approximate IP-based location lookup only when you open that screen, and you can turn it off in Settings. Explore uses only the map cursor you move.

Is RadioCLI free?

Yes. RadioCLI is MIT licensed and the source is on GitHub at Ciphore/RadioCLI.

Internet radio for your terminal · v0.2.6

The world’s radio.
At your command.

RadioCLI is an open-source internet radio player with a full-screen terminal interface and a scriptable CLI. Discover and stream stations from around the world without leaving your terminal. No account. No cloud library.

npm install -g @ciphore/radiocli

    Field guide

    Every screen is a way to find something to hear.

    The real thing runs in your terminal, plays through mpv, and keeps its library and listening history on your machine.

    Plate 01 · Explore

    Explore the world map

    A braille world map sits beside the station list. Move one scan cursor and the list reloads around that coordinate, sorted by real distance rather than popularity.

    • WASD to nudge, Shift to jump, or click
    • Browse whole country lists
    • Nearby lists stations around your approximate location
    • Cached station atlas keeps working during directory outages
    Explore controls →

    Plate 02 · Search

    Search every station

    Search by station name or genre, then narrow by country, language, codec, and bitrate. Results show exactly what you are about to tune.

    • radiocli search jazz --pick
    • radiocli play --country JP
    • Add any direct HTTP(S) stream URL
    Search commands →

    Plate 03 · Library

    A library that stays on your machine

    Favorites, recent stations, and imported streams live in one local library. There is no account to create and nothing to sync.

    • Import M3U, PLS, or XSPF; export M3U
    • Named presets: radiocli play work
    • Track history, JSON backup and restore
    Privacy & storage →

    Plate 04 · Stats

    Listening stats

    A 52-week activity graph with listening time, session counts, active days, streaks, and your most-listened station, recorded across TUI and CLI sessions.

    • Stored locally, never uploaded
    • Selectable display colors
    • radiocli stats from the shell
    Stats commands →

    Plate 05 · Receivers

    424 receiver styles, 48 themes

    Braille animation, ASCII geometry, waves, fire, cityscapes, and the Gallop display. Switch without interrupting playback. Receivers move only while audio is really playing; a dead stream shows a flat zero-signal frame.

    • v next receiver, t next theme
    • Full, compact, and micro layouts
    • Reduced motion, screen readers, ASCII-only, NO_COLOR
    Try all 424 receivers →

    Plate 06 · Alarms

    Alarms and sleep timer (beta)

    One-time or recurring alarms with timezones, independent volume, fade-in, fallback stations, snooze, and auto-stop. Native OS scheduling lets them ring after the terminal is closed.

    • launchd, Task Scheduler, or systemd user timers
    • Verify alarm setup rehearses the whole path
    • Beta: keep a second alarm for anything critical
    Alarm guide →

    Agent control over MCP

    An optional Model Context Protocol server gives coding assistants typed tools for discovery, playback, favorites, stats, alarms, AirPlay, and appearance.

    • radiocli setup --mcp
    • Opt-in, local, stdio transport
    • Agents can play only library stations or RadioCLI search results

    Quick start

    Three routes to first signal.

    Setup shows a plan before it installs any playback tools. radiocli doctor reports what your machine can do.

    npm · Node.js 22+

    $ npm install -g @ciphore/radiocli
$ radiocli setup
$ radiocli

    Homebrew · macOS

    $ brew install ciphore/tap/radiocli
$ radiocli

    Also installs Node.js, mpv, and FFmpeg.

    npx · no install

    $ npx @ciphore/radiocli

    Needs Node.js 22+ and a player such as mpv.

    Shell & keyboard

    Eight commands, six keys.

    radiocli play jazz starts background playback and returns your prompt. If the full-screen interface is open, commands control that player instead.

    radiocli …

    play [station]Find and play a station, or continue listening
    pausePause the current station
    nextTune the next station in the queue
    nowShow the station, track, and volume
    volume 40Set volume from 0 to 100
    favoriteSave the current station
    favoritesList saved stations
    stopStop listening and close the background player

    In the interface

    ← →Switch screens
    ↑ ↓ EnterSelect and tune a station
    spacePause or resume
    fToggle a favorite
    v / tReceiver style / color theme
    ? / qShow shortcuts / quit

    Playback

    Pause, volume, mute, and live track metadata through mpv, with media keys and a sleep timer. ffplay and VLC work as fallbacks.

    Scripting

    --json, --plain, --quiet, and --no-input on listener commands, plus shell completion and now --watch.

    Stream recovery

    Directory mirrors, broken-stream skipping, cached lists, offline browsing, and a low-bandwidth mode.

    AirPlay (experimental)

    Discover network receivers and switch audio output from the terminal, passcodes included.

    Custom stations

    Add direct stream URLs with ICY metadata lookup. Import M3U, PLS, or XSPF playlists.

    Accessible

    Keyboard, mouse, and trackpad. Screen-reader output, reduced motion, ASCII rendering, and limited-color terminals.

    Questions

    Asked and answered.

    What is RadioCLI?

    RadioCLI is a free, open-source internet radio player that runs in your terminal. It has a full-screen terminal interface (TUI) for browsing and listening, and a scriptable command line for starting, pausing, and switching stations from your shell.

    How do I install RadioCLI?

    With Node.js 22 or newer: npm install -g @ciphore/radiocli, then radiocli setup. On macOS, brew install ciphore/tap/radiocli also installs Node.js, mpv, and FFmpeg. To try it without installing, run npx @ciphore/radiocli.

    Do I need an account or subscription?

    No. There is no account, no sign-in, and no cloud library. Favorites, recent stations, settings, track history, and listening stats are stored on your machine, with JSON backup and restore.

    Which operating systems are supported?

    macOS (Apple silicon and Intel), Ubuntu Linux (x64 and arm64), and Windows (x64 and arm64) are tested in CI on Node.js 22 and 24. FreeBSD, OpenBSD, and NetBSD are supported for the core package route. Other platforms such as Alpine, WSL, and Termux are experimental.

    What do I need for audio playback?

    RadioCLI plays streams through mpv, which provides pause, volume, mute, media keys, and live track metadata. ffplay and VLC work as playback-only fallbacks. radiocli setup shows a plan and helps install the tools for your system; radiocli doctor checks what is available.

    Where do the stations come from?

    Station discovery uses the public Radio Browser directory, with cached results that stay available during provider outages. You can also add any direct HTTP(S) stream URL and import M3U, PLS, or XSPF playlists.

    Can an AI assistant control RadioCLI?

    Yes, if you opt in. radiocli setup --mcp registers a local Model Context Protocol (MCP) server with typed tools for discovery, playback, favorites, stats, alarms, AirPlay, and appearance. It runs over stdio on your machine, and agents can only play stations from your library or from RadioCLI's own search results.

    Can RadioCLI wake me up with a radio station?

    Alarms are in beta. You can schedule one-time or recurring alarms with timezones, fade-in, fallback stations, snooze, and auto-stop. They register with launchd, Task Scheduler, or a systemd user timer, so the terminal does not need to stay open. Use a second device for anything critical.

    What does RadioCLI send over the network?

    It resolves public stream URLs and hands playback to your local player; it does not proxy audio. Nearby uses an approximate IP-based location lookup only when you open that screen, and you can turn it off in Settings. Explore uses only the map cursor you move.

    Is RadioCLI free?

    Yes. RadioCLI is MIT licensed and the source is on GitHub at Ciphore/RadioCLI.
